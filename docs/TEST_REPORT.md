## 本版回归重点

- 全宽列表默认展示；点击进入阅读，返回列表。
- 账户、文件夹、搜索、返回和后续详情请求使旧详情结果失效；过期失败不污染当前画面。
- 已加载 80 封邮件的静默刷新保持分页范围与滚动偏移。
- 连续点击“加载更多”不重复发请求；页边界重复邮件按 ID 去重。
- 新邮件默认当前账户；未连接邮箱时写信进入账户设置。
- 320px 手机阅读和写信无横向溢出；设置连接/关闭操作固定可见。
- 已发送列表包含收件人，但仍排除正文、Bcc、Cc、附件。
- 旧版持久化已发送摘要没有收件人时，仅对当前页缺失字段的记录做一次批量补全（最多 100 封），无需数据库迁移、重新授权或重新同步；正常摘要不读取正文。
- 分页边界回归：页外旧摘要的正文故意不可解码，当前页仍正常返回，确保不会在分页前载入所有已发送正文。
- 原发送确认、结果不明禁止盲目重发、纯文本和 OAuth 安全回归继续通过。

## 边界与后续构建验证

测试邮件、账户和收件人全部为合成数据，没有向真实邮箱发送邮件，也没有验证真实 OAuth 应用或授权。

本地没有重跑 PostgreSQL 集群；仓库现有 GitHub Actions 会针对实际提交运行同组 PostgreSQL 17 测试、集成 JAR 冒烟与打包。应查看该提交的 workflow 结果，不把先前提交的 CI 当成本版结果。

浏览器端到端未运行：当前 shell Chromium 无法创建所需 Unix socket，支持的云端浏览器也无法访问执行沙箱的 loopback 服务。上述截图来自应用真实 Flutter widget 渲染器，不是 HTML 设计稿。原生平台发布构建、Docker 运行和生产部署不在此本地报告的验证范围。

本次不修改数据库架构、OAuth 密钥、服务器配置或附件删除 API。上线应保留现有数据库及 `MAIL_ENCRYPTION_KEY`，由部署流程独立备份与验收。
