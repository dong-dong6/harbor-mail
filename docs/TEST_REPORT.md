## 新增后端安全与兼容覆盖

44 个生产模式 OAuth 测试，加 1 个演示模式保护测试，覆盖：

- 未认证读写拒绝、Bearer 会话、禁止缓存和 CORS PUT
- 三组提供商分离、未知提供商/字段拒绝、HTTPS 回调与租户校验
- 密钥密文存储、响应无明文、空白保留、显式清除、环境恢复
- 整组数据库覆盖、无隐式环境密钥回落、保存后动态生效
- 并发版本拒绝、防止旧窗口覆盖、版本在恢复环境后仍递增
- 旧凭据身份绑定、加密密钥与 token 值保留、重新授权提示、兼容恢复
- 重启重建设置、故障事务回滚、未完整配置禁用授权
- OAuth state 一次性/过期/跨提供商拒绝
- 授权换 token 或读取身份期间更改配置，不写入过期结果
- 刷新期间换配置、新授权与旧刷新竞争的 CAS 保护

故障回滚测试会有意触发数据库约束错误；测试日志只记录异常类型，不包含密钥。它们不是测试失败。

## 新增前端覆盖

- 加载/错误/重载、只读与演示禁用
- 密钥掩码、响应字段忽略、留空保留、确认清除和撤销
- 环境恢复确认、版本冲突、断网结果不明时禁止盲目重试
- 400 校验错误后安全重试、未完整配置不伪装成已连接
- 重复保存、请求期间返回/Escape、取消切换时保留编辑
- 控制器销毁后的异步响应、窄屏滚动与设置入口能力刷新

## 未运行或不能由这些测试证明

- 真实 Google / Microsoft 应用注册、密钥有效性、同意授权、企业租户策略及邮箱收发
- 用户当前服务器的升级、备份恢复、HTTPS 反向代理或实际域名验收
- 浏览器端到端交互自动化（本次使用 widget 交互、渲染截图和真实 HTTP 联调）
- Docker 运行时与原生 Android/iOS/Windows/macOS/Linux 发布构建、签名或真机验证

配置完整仅代表本地字段/格式校验通过，不能解释为已连接真实邮箱。首次升级必须保留原 OAuth 环境变量完成旧凭据绑定，并始终保留原 `MAIL_ENCRYPTION_KEY`。详见 [升级说明](OAUTH_SETTINGS_UPGRADE.md)。
