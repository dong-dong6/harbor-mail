Harbor Mail v0.3.2 开发测试版

- 密码、通行密钥或网页批准扫码登录可选择“记住此设备”，短期 access 与可轮换 refresh 配合，正常使用自动续期。
- 默认 access 15 分钟，连续 30 天未使用或初次授权满 365 天需重新登录；实际期限以设置中显示为准。退出或网页撤销会使设备授权失效。
- refresh 使用 Android Keystore 加密保存，不存密码；网络中断、轮换丢包和重启可恢复，离线不会仅因短期 access 到期清除记住状态。
- 指纹 / 系统验证保护独立且默认关闭，手动启用、首次验证成功后生效。解锁后的自动续期不会反复弹验证。
- 被动轮询不延长无人使用的授权，返回前台或主动操作会续期。设备名称默认取厂商与型号，仍可编辑。
- 保留安全 HTML 阅读、网页响应式登录和应用内更新签名校验。

开发测试 APK 使用临时调试签名，跨 CI 构建可能无法覆盖安装。只有包名和签名证书一致、versionCode 更高的构建才可保留数据更新。签名不一致会阻止更新，不建议为更新而丢失本地数据。
真实设备安装、系统认证、文件选择器生命周期与冷启动仍需设备验收。未建立正式签名或 Android 原生 Passkey 域名信任；通行密钥功能取决于当前平台和已配置的可信关联。
